# The text kitchen

No-nonsense, vetted cooking recipes as plain static HTML. Every recipe has been cooked and checked before it goes in; untested ones get removed. The whole site lives in `dist/` and can be served from any static host with no build step.

The favicon is the `chef-hat` icon from [Lucide](https://lucide.dev) (ISC license, see `THIRD-PARTY-NOTICES.md`).
